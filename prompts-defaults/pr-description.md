---

Write a pull request for branch `{{branch}}` (task {{task_id}}) targeting `{{base}}`.

Commits:

```
{{commits}}
```

Changed files:

```
{{files}}
```

Diff:

```diff
{{diff}}
```

Produce exactly this shape:

TITLE: one line, imperative, under 72 characters, prefixed with the task id when there is
one.

Then the body, in markdown:

- **What changed** — a few bullets a reviewer can scan, grouped by area rather than by
  file when that reads better.
- **Why** — the problem this solves or the behavior it enables.
- **Review notes** — anything non-obvious: decisions taken, trade-offs, follow-ups left
  out on purpose, and what you verified (tests run, manual checks). Say plainly if
  something is untested.

No filler sections, no "generated by", no restating the diff line by line.
